# 컨텍트 포크 (CT 포크)

미스키의 **버터스콘 포크**를 기반으로 기능을 추가·수정한 비공식 포크입니다. 초코픽·체리픽 등 다른 포크에서 가져온 기능을 중심으로 구성했으며, 일부 기능은 직접 개발하거나 수정했습니다.

## 주요 기능

- 서버 연결 끊김 알림에 **‘표시 안 함’** 옵션 추가
- 채팅 연합 기능을 지원하는 포크 간 메시지 연합 지원 (예: **컨텍트 포크 ↔ 체리픽**)
- 통화 중 녹음·녹화 기능 추가

## 사용 안내

현재 개발 및 테스트 단계입니다. 개발 과정에서 미숙한 부분이 있어 오류나 예기치 않은 동작이 발생할 수 있습니다. 운영 환경에 적용하기 전 충분히 테스트하고 데이터를 백업해 주세요.
